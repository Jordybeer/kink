# v3 audit — UI + UX

## FIX (broken / wrong)

### Accessibility / HTML validity
- **Home CTAs `aria-disabled` on `<div>` without `tabIndex`** — keyboard users can't reach them. `app/page.tsx` use real `<button disabled>` or add `tabIndex={0}`.

### Layout
- **Profile FAB export buttons ~38px height** — below 44px minimum. `app/profile/[id]/page.tsx` → `py-3` or `min-h-[44px]`.

---

## SUGGEST (polish / friction)

### Touch targets
- **Edit/delete buttons on profile cards `p-2`** — ~32×32px. `app/page.tsx` L529–531 → `p-3` or `min-w-[44px] min-h-[44px]`. Add `gap-1` between the three right-side actions.
- **Contract preamble toggle no padding** — ~12px tap target. `app/contract/page.tsx` L476 add `py-2 px-1 inline-block`.
- **Avatar remove button 20×20px** — `components/ProfileHero.tsx` L138 → `w-7 h-7`, offset `-top-1 -right-1` or reveal only on hover/focus overlay.

### Navigation / flows
- **Home compare CTA always uses first two profiles** — `app/page.tsx` L204 `profiles.slice(0,2)`. Add note or default to last-viewed pair.
- **Profile empty state doesn't guide user to edit list** — "Lijst bewerken" toggle can be off-screen. When `totalRated === 0`, auto-expand or highlight the toggle. `app/profile/[id]/page.tsx`.
- **Scrollspy `activeCategory` lags on programmatic scroll** — IntersectionObserver not reset on pill tap. `app/profile/[id]/page.tsx` call `setActiveCategory(cat)` immediately on tap before `scrollToCategory`.
- **"Meer" section header not collapsible** — inconsistent with all other `CategorySection` accordions. `app/profile/[id]/page.tsx` wrap in `<button aria-expanded>` with local collapse state.

### Feedback / disclosure
- **"Besproken" state session-only, no disclosure** — lost on refresh, no warning. `app/compare/page.tsx` add "(tijdelijk)" note or persist to `sessionStorage`.
- **Contract traffic light buttons no text labels** — colour only, aria-label never shown to sighted users. `app/contract/page.tsx` add label beneath each dot or tooltip on hover/long-press.
- **KinkRow Ervaring toggle null state ambiguous** — `aria-pressed` goes true→false but label doesn't change. `components/KinkRow.tsx` show "Ervaring ✓" when active.

### Layout / visual
- **Compare filter strip wraps on narrow screens** — orphaned pills on second row. `app/compare/page.tsx` L233 → `overflow-x-auto no-scrollbar` horizontal scroll.
- **CategorySection pip dots row** — up to 20 dots at 6px can crowd the count and "Sla over" on narrow phones. `components/CategorySection.tsx` cap at 12 pips or replace with `h-1` progress bar.
- **BottomNav no `padding-bottom: env(safe-area-inset-bottom)`** — label text sits on home indicator. `components/BottomNav.tsx` add safe-area padding.
- **Settings sheet no drag handle** — import/delete sheets have the `w-10 h-1` pill indicator; settings does not. `app/page.tsx` add handle + swipe-to-dismiss parity.
- **ProfileHero stats row no scroll affordance** — scrollable but no fade gradient hint. `components/ProfileHero.tsx` add right-edge fade overlay.
- **KinkRow kink name `text-[17px]`** — non-standard size. `components/KinkRow.tsx` L98 → `text-base` or `text-lg`.
- **Contract emoji bullets** — 🔴🤍✏️💬 render inconsistently across platforms. `app/contract/page.tsx` L615 → coloured `•` spans or consistent Lucide icons.
- **Settings gear `⚙` Unicode** — inconsistent with Lucide usage elsewhere, low contrast at `var(--text2)`. `app/page.tsx` L220 → `<Settings size={18} />` at `var(--text)` on hover.

### Accessibility
- **No focus trap on settings/delete sheets** — tab escapes to page content behind. `app/page.tsx` use `@radix-ui/react-dialog` (already in deps) or manual focus trap.
- **Experience-level / relatiestatus controls use `<p>` not `<fieldset>`** — no semantic association for screen readers. `app/page.tsx` L258–336 → `<fieldset>` + `<legend>` for groups of `aria-pressed` buttons.
- **Compare heatmap truncated names** — `catAbbrev` cuts to 8 chars, no visible tooltip on mobile. `app/compare/page.tsx` ensure `aria-label={cat}` is present; add long-press popover for sighted mobile.

### Code hygiene
- **Confetti `<style>` injected in render** — `app/compare/page.tsx` L381 re-inserts keyframes every render cycle. Move `confetti-pop` to `globals.css`.
- **KinkRow comment textarea hard `maxHeight: 9rem`** — stops expanding silently while char counter still has headroom. Remove cap or add `overflow-y: auto` with visible scrollbar.
